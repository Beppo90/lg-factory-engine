### PM-3.2 — Playbook Build-Out **[AHORA OBLIGATORIO]**
**CAMBIO CRÍTICO:** Pasó de **OPCIONAL** a **OBLIGATORIO**  
**v2.0 STATUS:** MANDATORY (8 documentos por RAP, 1 por sesión)  
**Generación:** 1 documento por sesión (S1-S8)  
**OUTPUT por sesión:**

**Crítico porque:** PM-3.2 es el documento que el instructor va a usar REALMENTE en clase. Si no se aprueba, las clases serán caóticas.

**v2.0 STATUS:** EXPANDED

**Las 5 sub-fases ABP:**
1. **Planeación:** Qué vamos a hacer (definir problema/proyecto)

3. **Desempeño:** Hacerlo en contexto laboral simulado o real
4. **Presentación:** Comunicar resultado (oral + artefacto)
5. **Evaluación reflexiva:** Qué aprendí (sin puntos formales)

**Arquetipos:** 5 (Professional Simulation / Problem-Solution / Production / Collaborative / Gamified)

## PARÁMETROS ESTÁNDAR UNIVERSALES v2.0

Estos aplican a **todos** los 22 PMs sin excepción:

### 1. Nivel CEFR

```
ESTÁNDAR:  A1.1 — A1.2
VARIABLE:  Sí (instructor puede variar a A2 en casos especiales)
REALIDAD:  98% aprendices SENA llegan A1
```

### 2. Duración por Guía

```
1 GUÍA = 24 HORAS = 1 MACROTEMÁTICA

TÉCNICO (≈180h):
├── 6 macrotemáticas × 1 guía = 6 guías
├── Directo: 144h (6 × 24h)
└── Autónomo: 36h

TECNOLÓGICO (≈350h):
├── 6 macrotemáticas × 2 guías = 12 guías
├── Directo: 288h (12 × 24h)
└── Autónomo: 62h
```

### 3. Nivel Bloom y Dificultad

```
BLOOM:     Relativo — varía por actividad
           L1-2 (S1) → L2-3 (S2-S5) → L4-6 (Workbook EXTEND, PM-3.5)

DIFICULTAD TÉCNICA: SIMPLE
           Input comprensible en entornos ocupacionales
           Procesos procedimentales de complejidad media-baja
```

### 4. Needs Analysis

```
ESTADO:   SE OBVIA como paso separado

RAZÓN:    - Contenido ya parte del entorno ocupacional
          - Análisis curricular completo (PM-1.2)
          - PM-2.1 (The Spark) cumple función diagnóstica
```

### 5. RAPs y Competencia — Regla de Inserción

```
OBLIGACIÓN: Cada PM debe dejar ESPACIO para que instructor
            inserte manualmente competencia + RAP

OPTIONAL EXECUTION: Prompt funciona con o sin ellos
NOTA: Transcripción literal de SOFÍA Plus = responsabilidad instructor
```

### 6. Formatos GFPI

```
ESTADO: Pendiente integración completa
PLAN:   - Primero: sistema completo automatizado ✓
        - Segundo: integrar GFPI-F-135 (Guía del Aprendiz) como capa salida
```
